# VSC Themes

Updates work by pulling changes.

## Gruvbox Dark

Dark theme for VSC/Code OSS/VSCodium, has some color changes, e.g. darker surfaces, and uses the [Gruvbox palette](https://github.com/morhetz/gruvbox) for syntax/terminal colors.

### Installation

1. Clone/download the repo (any folder you want to save the theme in)
2. Press `Ctrl+Shift+P`, run `Developer: Install Extension from Location...`, select the folder
3. Run `Developer: Reload Window`
4. Run `Preferences: Color Theme`, select `Gruvbox Dark`
